# React Redux (PART 1)

> **Projet réalisé dans le cadre de Holberton School**  
> **Auteur : Johann Kerbrat, Engineering Manager at Uber Works**

---

## 📚 Description

Ce projet a pour objectif de te familiariser avec Redux, la gestion d’état avancée dans les applications React. Tu apprendras à manipuler des slices, à dispatcher des actions, à accéder à l’état global, et à structurer un store Redux moderne.

---

## 🎯 Objectifs pédagogiques

À la fin de ce projet, tu seras capable d’expliquer :

- Pourquoi Redux est un outil puissant pour la gestion d’état
- Comment organiser l’état avec des slices Redux
- Ce qui se passe lors du dispatch d’une action Redux
- Le rôle et la structure du Redux Store
- Comment accéder à l’état avec `useSelector`
- Comment dispatcher des actions avec `useDispatch`

---

## 🛠️ Technologies & Prérequis

- **Node.js** 20.x.x
- **npm** 10.x.x
- **Jest** 29.7.0 (installer globalement : `npm install -g jest@29.7.0`)
- **React** & **Redux Toolkit**

---

## 📦 Installation

1. Clone le repo :
	```bash
	git clone <repo-url>
	cd holbertonschool-web_react/react_redux-part1
	```
2. Installe les dépendances :
	```bash
	npm install
	```
3. Lance les tests :
	```bash
	jest
	```
