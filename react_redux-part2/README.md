# React Redux (PART 2)

> **Projet réalisé dans le cadre de Holberton School**  
> **Auteur : Johann Kerbrat, Engineering Manager at Uber Works**

---

## 📚 Description

Ce projet approfondit l’utilisation de Redux dans React, en mettant l’accent sur la performance, la compréhension des re-renders, et l’optimisation via les sélecteurs mémoïsés. Tu exploreras également les différences entre `useState` et `useRef` pour une gestion efficace de l’état et des références.

---

## 🎯 Objectifs pédagogiques

À la fin de ce projet, tu seras capable d’expliquer :

- Les problèmes de performance dans React et comment les diagnostiquer
- L’intérêt et l’utilisation des sélecteurs Redux mémoïsés

---

## 🛠️ Technologies & Prérequis

- **Node.js** 20.x.x
- **npm** 10.x.x
- **Jest** 29.7.0 (installer globalement : `npm install -g jest@29.7.0`)
- **React** & **Redux Toolkit**

---

## 📦 Installation

1. Clone le repo :
	```bash
	git clone <repo-url>
	cd holbertonschool-web_react/react_redux-part2
	```
2. Installe les dépendances :
	```bash
	npm install
	```
3. Lance les tests :
	```bash
	jest
	```
